## Generating `subbasins.nc`

The `subbasins.nc` file contains 2D masks for the major ocean basins used by NEMO:

- `pacmsk` – Pacific Ocean
- `atlmsk` – Atlantic Ocean
- `indmsk` – Indian Ocean
- `socmsk` – Southern Ocean

Each variable is a binary ocean mask (`1 = ocean`, `0 = land`).

For the Pliocene configuration this file was generated by adapting the standard PI basin masks to the new land–sea mask.

### 1. Required input files

Place the following files in your working directory:

```text
orig_subbasins.nc
orig_domain_cfg.nc
mesh_mask.nc
```

where:

- `orig_subbasins.nc` is the standard GC5 PI `subbasins.nc`
- `orig_domain_cfg.nc` is the PI `domain_cfg.nc`
- `mesh_mask.nc` is the new mesh mask generated for the Pliocene bathymetry

---

### 2. Run the script

Run:

```bash
python make_subbasins.py
```

Located at `/gws/pw/j25/past2future/users/gpontes/HadGEM3-GC5-0/LP_exp_bc/make_ocean/`

This script:

- interpolates the basin masks onto the new grid using ORCA grid indices (`i`,`j`);
- applies the Pliocene land–sea mask from `mesh_mask.nc`;
- restores ocean points along the ORCA periodic boundaries:
  - first and last longitude columns and northernmost row.

The script writes:

```text
subbasins.nc
```

---

### 3. Quick check

Open in `ncview`:

```bash
module load ncview
ncview subbasins.nc
```

Check each mask individually:

```text
pacmsk
atlmsk
indmsk
socmsk
```

Recommended checks:

- Atlantic basin extends continuously through the North Atlantic;
- Indian basin ends at the Maritime Continent;
- Indonesian Throughflow belongs to the Pacific;
- no gaps where Southern Ocean meet continents;
- no artificial land points along the ORCA longitude seam or northern row.

---

### Notes

This workflow assumes the horizontal grid remains unchanged (**eORCA1 / 362 × 332**) and only the land–sea mask differs.

Using grid-index interpolation avoids longitude seam issues at the periodic ORCA boundary and preserves basin masks from the PI control while adapting to the new palaeogeography.
